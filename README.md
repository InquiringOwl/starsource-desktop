# StarSource

An astrology console by Wolfie's Coven: natal, transit, progression, solar arc, return, harmonic, synastry and composite charts computed with the
Swiss Ephemeris (compiled to WebAssembly), every angle to the arcsecond, in a tactical-HUD interface.

- Desktop: [Releases](https://github.com/InquiringOwl/starsource-desktop/releases) (macOS, Windows, Linux; Android APK too). Installed copies update themselves.
- Phones and browsers: [inquiringowl.github.io/starsource-desktop](https://inquiringowl.github.io/starsource-desktop/), then Add to Home Screen / Install app. Works offline.
- Develop: `npm install`, `npm start`. Checks: `npm run check`. Project brief: [CLAUDE.md](CLAUDE.md).
